### 🏭 NISHKARSHA

AI-assisted material-data harmonization concept for CPSEs.

The solution works with different forms of material data such as:

`Excel` `CSV` `PDF` `Scanned Documents`

and focuses on:

- Material information extraction
- Material matching
- Code and specification comparison
- Confidence-based results
- Human validation
- Traceability of original material codes

The approach focuses on **automation with human oversight**, rather than replacing existing systems.
